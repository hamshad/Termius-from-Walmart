# Phase 03 Plan 01: UX Polish

## Objective
Add loading spinners, connection feedback, file metadata display, async file transfers, keyboard shortcut overlay, and timed message auto-clear to create a polished, responsive user experience.

## Tasks

### Task 1: Async SFTP Connection with Spinner
- Add custom tea.Msg types for SFTP connection lifecycle (start, success, error)
- Add a "Connecting..." view state with spinner animation using bubbletea tick
- Make ConnectSFTP launch asynchronously via tea.Cmd
- Show spinner while connecting, transition to SFTPView on success, show error on failure

### Task 2: SSH Connection Feedback
- Show "Connecting to {server}..." message before tea.ExecProcess hand-off
- Add brief visual feedback so user knows connection is being established

### Task 3: File Metadata in SFTP
- Enhance FileItem to carry size, permissions, and modification time
- Update FileDelegate to render metadata (size in human-readable format, permissions, date)
- Update loadLocalFiles and loadRemoteFiles to populate metadata

### Task 4: Async File Transfers with Progress
- Add tea.Msg types for transfer lifecycle (start, progress, complete, error)
- Make performCopy async via tea.Cmd
- Show transfer progress bar with file name during transfer
- Refresh file lists on completion

### Task 5: Keyboard Shortcut Help Overlay
- Add HelpView state toggled by '?' key
- Create help overlay showing all keybindings organized by view
- Render as centered modal overlay

### Task 6: Timed Message Auto-Clear
- Add a tea.Tick-based message timer
- Auto-clear m.Message after 3 seconds
- Support across all views

## Verification
- `go build -v .` compiles without errors
- `go test ./...` passes all tests
- All views render properly (no layout breaks)

## Success Criteria
- SFTP connection shows spinner while connecting
- SSH connection shows feedback before hand-off
- SFTP file lists show size, permissions, mod time
- File transfers show progress and don't block UI
- '?' toggles help overlay in all views
- Messages auto-clear after timeout
